PARTE 1: ESTRUCTURA BÁSICA DE HTML
═══════════════════════════════════════════════════════════════════════════════

Un archivo HTML tiene esta estructura:

<!DOCTYPE html>
<html lang="es">
<head>
  <!-- Aquí va la configuración y estilos -->
  <meta charset="UTF-8">
  <title>Mi Página</title>
  <style>
    /* Los estilos CSS van aquí */
  </style>
</head>
<body>
  <!-- Aquí va el contenido visible -->
</body>
</html>

Desglose:
- <!DOCTYPE html>     → Le dice al navegador que es HTML5
- <html>              → Contenedor principal
- <head>              → Información sobre la página (no se ve)
- <body>              → Contenido que sí se ve
- <style>             → Aquí escribimos CSS para decorar

PARTE 2: CÓMO AGREGAR BOTONES SIMPLES
═══════════════════════════════════════════════════════════════════════════════

Un botón básico se crea con la etiqueta <button>:

<button>Haz clic aquí</button>

Botón con ID (para identificarlo en JavaScript):

<button id="mi-boton">Haz clic aquí</button>

Botón con clase (para estilos CSS):

<button class="boton-principal">Enviar</button>

Botón con múltiples clases:

<button class="boton-principal boton-grande">Enviar</button>

Botón con tipo específico:

<button type="button">Botón normal</button>
<button type="submit">Enviar formulario</button>
<button type="reset">Limpiar formulario</button>

Botón deshabilitado:

<button disabled>No se puede hacer clic</button>

Botón con atributos especiales:

<button id="upload-button" class="boton-archivo" type="button">
  📎 Cargar archivo
</button>

PARTE 3: INTRODUCCIÓN A CSS PARA DECORACIÓN
═══════════════════════════════════════════════════════════════════════════════

CSS es el lenguaje que usamos para decorar HTML. Va dentro de <style>

Sintaxis básica de CSS:

selector {
  propiedad: valor;
  otra-propiedad: valor;
}

Ejemplo simple:

<style>
  button {
    background-color: blue;
    color: white;
    padding: 10px 20px;
  }
</style>

Esto hace que TODO botón en la página tenga:
- Fondo azul
- Texto blanco
- Espaciado interno (padding) de 10px arriba/abajo, 20px izquierda/derecha

PROPIEDADES CSS MÁS COMUNES:

1. COLORES:
   - background-color: azul;       (color de fondo)
   - color: blanco;                (color del texto)
   - border-color: rojo;           (color del borde)

2. TAMAÑO Y ESPACIADO:
   - width: 200px;                 (ancho)
   - height: 50px;                 (alto)
   - padding: 15px;                (espacio dentro, alrededor del contenido)
   - margin: 20px;                 (espacio fuera, alrededor del elemento)
   - border-radius: 10px;          (redondear esquinas)

3. TEXTO:
   - font-size: 16px;              (tamaño de texto)
   - font-weight: bold;            (grosor del texto: bold, normal, 700)
   - text-align: center;           (alineación: left, center, right)
   - letter-spacing: 2px;          (espacio entre letras)

4. BORDES:
   - border: 2px solid black;      (borde de 2px, línea continua, color negro)
   - border-width: 1px;            (grosor del borde)
   - border-style: solid;          (tipo: solid, dashed, dotted, double)

5. SOMBRAS Y EFECTOS:
   - box-shadow: 0 4px 8px rgba(0,0,0,0.2);  (sombra)
   - opacity: 0.8;                 (transparencia: 0 = invisible, 1 = opaco)

PARTE 4: VARIABLES CSS (CUSTOM PROPERTIES)
═══════════════════════════════════════════════════════════════════════════════

Las variables CSS te permiten reutilizar valores sin escribirlos una y otra vez.

Cómo definir variables CSS:

<style>
  :root {
    --color-principal: #38bdf8;
    --color-oscuro: #0ea5e9;
    --color-texto: #e2e8f0;
    --color-fondo: #0f172a;
    --espaciado: 20px;
    --radio-boton: 12px;
  }
</style>

:root = aplica las variables a TODO el documento

Cómo usar las variables:

<style>
  button {
    background-color: var(--color-principal);
    color: var(--color-texto);
    border-radius: var(--radio-boton);
    padding: var(--espaciado);
  }
</style>

VENTAJAS:
- Si cambias el valor en :root, cambia en TODOS los lugares
- Código más limpio y mantenible
- Fácil de hacer temas (claro/oscuro)

Ejemplo práctico:

:root {
  --azul: #38bdf8;
  --verde: #22c55e;
}

button {
  background: var(--azul);
}

button:hover {
  background: var(--verde);
}

EJEMPLO 3: Botón con gradiente (degradado)

HTML:
<button class="boton-gradiente">Enviar</button>

CSS:
.boton-gradiente {
  padding: 14px 28px;
  background: linear-gradient(135deg, #38bdf8, #0ea5e9);
  color: white;
  border: none;
  border-radius: 12px;
  font-size: 16px;
  font-weight: bold;
  cursor: pointer;

linear-gradient(135deg, color1, color2)
- 135deg = ángulo de la línea (0=arriba, 90=derecha, 135=diagonal)
- color1 = color inicial
- color2 = color final

═════════════════════════════════════════════════════════════════════════════

EJEMPLO 4: Botón con sombra

HTML:
<button class="boton-sombra">Con sombra</button>

CSS:
.boton-sombra {
  padding: 12px 24px;
  background-color: #38bdf8;
  color: white;
  border: none;
  border-radius: 8px;
  font-size: 16px;
  cursor: pointer;
  box-shadow: 0 4px 12px rgba(56, 189, 248, 0.3);

box-shadow: offsetX offsetY blur color;
- offsetX = cuántos píxeles a la derecha
- offsetY = cuántos píxeles hacia abajo
- blur = qué tan difuminada la sombra
- rgba(R,G,B,Transparencia) = color RGBA

PARTE 6: EFECTOS DE INTERACCIÓN (HOVER, ACTIVE, DISABLED)
═════════════════════════════════════════════════════════════════════════════

:hover = cuando pasas el ratón SOBRE el botón

HTML:
<button class="boton-interactivo">Hover me</button>

CSS:
.boton-interactivo {
  padding: 12px 24px;
  background-color: #38bdf8;
  color: white;
  border: none;
  border-radius: 8px;
  cursor: pointer;
  transition: all 0.3s ease;  /* Transición suave de 0.3 segundos */
}

.boton-interactivo:hover {
  background-color: #0ea5e9;  /* Azul más oscuro */
  transform: translateY(-2px); /* Sube 2px */
  box-shadow: 0 8px 16px rgba(56, 189, 248, 0.4);
}

transition: all 0.3s ease;
- all = anima TODAS las propiedades que cambien
- 0.3s = duración de la animación
- ease = tipo de animación (suave)

═════════════════════════════════════════════════════════════════════════════

:active = cuando haces CLIC (presionas hacia abajo)

.boton-interactivo:active {
  transform: translateY(0px);  /* Vuelve a su posición normal */
  box-shadow: 0 2px 4px rgba(56, 189, 248, 0.2);
}

═════════════════════════════════════════════════════════════════════════════

:disabled = cuando el botón está deshabilitado

HTML:
<button class="boton-interactivo" disabled>Deshabilitado</button>

CSS:
.boton-interactivo:disabled {
  opacity: 0.5;               /* Más transparente */
  cursor: not-allowed;        /* Cursor de "no permitido" */
  background-color: #94a3b8;  /* Gris */
}

PARTE 8: ANIMACIONES Y EFECTOS AVANZADOS
═════════════════════════════════════════════════════════════════════════════

ANIMACIONES CON @keyframes

@keyframes define cómo cambia algo a lo largo del tiempo

Sintaxis:

@keyframes nombre-animacion {
  0% {
    /* Estado inicial */
  }
  50% {
    /* Estado intermedio */
  }
  100% {
    /* Estado final */
  }
}

EJEMPLO 1: Animación de aparición

@keyframes aparecer {
  0% {
    opacity: 0;           /* Invisible */
    transform: translateY(10px);  /* 10px hacia abajo */
  }
  100% {
    opacity: 1;           /* Visible */
    transform: translateY(0);     /* En su posición normal */
  }
}

button {
  animation: aparecer 0.5s ease forwards;
}

animation: nombre duración easing
- nombre = "aparecer"
- duración = 0.5s (medio segundo)
- easing = ease (suave)
- forwards = mantiene el estado final

═════════════════════════════════════════════════════════════════════════════

TRANSFORMACIONES Y EFECTOS
═════════════════════════════════════════════════════════════════════════════

transform: permite modificar la posición, tamaño y rotación

Ejemplos:
- transform: translateX(10px);        /* Mover horizontalmente */
- transform: translateY(-5px);        /* Mover verticalmente */
- transform: scale(1.1);              /* Aumentar tamaño 10% */
- transform: rotate(45deg);           /* Rotar 45 grados */
- transform: skew(10deg);             /* Sesgar */

Combinado:
- transform: translateY(-2px) scale(1.05);

CONSEJOS FINALES
═════════════════════════════════════════════════════════════════════════════

1. SIEMPRE usa variables CSS (:root) para colores y espaciados
   - Facilita mantener consistencia
   - Permite cambiar temas rápidamente

2. Usa TRANSICIONES para hacer los cambios suaves:
   - transition: all 0.3s ease;

3. Haz que los botones sean ACCESIBLES:
   - Suficiente contraste de colores
   - Cursor pointer
   - Cambios visuales claros en hover

4. Prueba tus botones en el navegador:
   - Abre el archivo HTML en Chrome/Firefox
   - Prueba hover, click, responsive

5. ESTRUCTURA HTML limpia primero:
   - Luego agrega CSS
   - No mezcles HTML y estilos inline

6. USA FLEXBOX para alinear botones:
   - display: flex;
   - gap: 10px;
   - justify-content: center;
   - align-items: center;

7. MEDIA QUERIES para responsivo:
   @media (max-width: 600px) {
     .botones-grupo {
       flex-direction: column;
     }
   }
