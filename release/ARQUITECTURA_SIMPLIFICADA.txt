PARTE 3: FLUJO DE CONVERSACIÓN (EL USUARIO TÍPICO)
═══════════════════════════════════════════════════════════════════════════════

PASO 1: USUARIO LLEGA AL CHATBOT
────────────────────────────────
Usuario abre: http://localhost:5000
↓
Frontend carga HTML/CSS/JS
↓
Chatbot muestra saludo inicial
"¡Hola! Bienvenido a K83 FYC..."

PASO 2: USUARIO SELECCIONA UNA VACANTE
────────────────────────────────────────
Usuario: "Quiero ver vacantes"
↓
Frontend envía: POST /chat con { message: "Quiero ver vacantes", state: {} }
↓
app.py llama a: get_chatbot_response()
↓
chatbot.py detecta: "vacante" en el mensaje
↓
chatbot.py retorna: "¿Qué área te interesa?" + botones [Producción, Calidad, ...]
↓
Frontend muestra los botones

PASO 3: USUARIO SELECCIONA UN ÁREA
──────────────────────────────────
Usuario: Hace clic en "Producción"
↓
Frontend envía: POST /chat con { message: "Producción", state: { ... } }
↓
chatbot.py llama: get_vacantes_by_area("Producción")
↓
chatbot.py carga vacantes.json → Encuentra vacantes de Producción
↓
chatbot.py retorna: "Tenemos X vacantes. ¿Operativo o Gerencial?"
↓
Frontend muestra opciones

PASO 4: USUARIO SELECCIONA TIPO DE PUESTO
──────────────────────────────────────────
Usuario: "Operativo"
↓
chatbot.py detecta tipo: "operativo"
↓
chatbot.py retorna: "Realizaremos una entrevista. ¿Estás listo?"
↓
Frontend muestra botones: [Sí, No]

PASO 5: USUARIO RESPONDE PREGUNTAS DE ENTREVISTA
─────────────────────────────────────────────────
Usuario responde 3 preguntas:
- ¿Experiencia en turnos?
- ¿Disponibilidad?
- ¿Experiencia en manufactura?
↓
chatbot.py guarda respuestas en state['interviewAnswers']
↓
Después de 3 preguntas: "Ahora necesitamos tu CV en PDF"

PASO 6: USUARIO SUBE CV
───────────────────────
Usuario: Sube archivo PDF
↓
Frontend envía: POST /upload-cv con archivo
↓
app.py guarda archivo en: uploads/20260529_134500_cv.pdf
↓
app.py actualiza state: { cvUploaded: true, cvFilePath: "..." }
↓
app.py detecta: Área + Puesto + CV completados
↓
app.py llama: build_email_payload() en chatbot.py
↓
app.py llama: send_recruitment_email()
↓
SMTP envía correo a RH_EMAIL con CV adjunto
↓
Frontend muestra: "Tu CV fue enviado correctamente ✅"

PARTE 4: GESTIÓN DE VACANTES (EL SISTEMA JSON)
═══════════════════════════════════════════════════════════════════════════════

¿CÓMO FUNCIONA?

1. AL INICIAR EL SERVIDOR:
   chatbot.py lee vacantes.json
   ↓
   Carga todas las vacantes en memoria: vacantes = [...]
   ↓
   Carga todas las áreas en memoria: areas = [...]

2. DURANTE LA CONVERSACIÓN:
   Cuando usuario menciona un área:
   ↓
   chatbot.py llama: get_vacantes_by_area("Producción")
   ↓
   Busca en la lista en memoria (muy rápido)
   ↓
   Retorna vacantes que coinciden

3. SI RH EDITA vacantes.json:
   Abre el archivo
   ↓
   Modifica una vacante (salario, requisitos, etc.)
   ↓
   Guarda el archivo
   ↓
   LOS CAMBIOS SE CARGAN LA PRÓXIMA VEZ que se reinicie el servidor

⚠️ IMPORTANTE: Para que los cambios tomen efecto:
   - Si el servidor está corriendo: Presiona Ctrl+C para detenerlo
   - Ejecuta nuevamente: python app.py
   - Los nuevos cambios se cargarán

PARTE 5: ENVÍO DE CORREOS (EMAIL CON SMTP)
═══════════════════════════════════════════════════════════════════════════════

CUANDO SE DISPARA:
─────────────────
- Usuario sube CV
- app.py detecta que la postulación está "completa"
- Llama a: send_recruitment_email(payload)

QUÉ SUCEDE:
──────────
1. send_recruitment_email() construye un mensaje de correo con:
   - Remitente: MAIL_FROM (de .env)
   - Destinatario: RH_EMAIL (de .env)
   - Asunto: "[K83 FYC] Nueva Postulación - Nombre - Área"
   - Cuerpo: Información del candidato en HTML
   - Adjuntos: CV en PDF

2. CONECTA al servidor SMTP (ej: smtp.gmail.com:587)
   - Usa credenciales de .env: MAIL_USER + MAIL_PASS
   - Inicia TLS para seguridad

3. ENVÍA el correo
   - Si funciona: Retorna { success: true }
   - Si falla: Retorna { success: false, message: "error" }

4. Frontend muestra al usuario:
   - Si éxito: "Tu CV fue enviado correctamente ✅"
   - Si fallo: "Hubo un error. Intenta más tarde."

VARIABLES DE .env REQUERIDAS:
──────────────────────────────
MAIL_HOST    = Servidor SMTP (ej: smtp.gmail.com)
MAIL_PORT    = Puerto (ej: 587)
MAIL_USER    = Usuario SMTP (tu email)
MAIL_PASS    = Contraseña de aplicación
RH_EMAIL     = Correo destino
MAIL_FROM    = Remitente

ESCENARIO 1: Agregar una nueva pregunta en la entrevista

Paso 2: Busca la función get_chatbot_response()
Paso 3: Encuentra la sección de entrevista (busca "interview_stage")

    elif next_state.get('interview_stage') == 'q3_nueva_pregunta':

            next_state['interviewAnswers'].append('✓ Respuesta positiva')

            next_state['interviewAnswers'].append('✗ Respuesta negativa')
        
        response = "Perfecto, hemos terminado la entrevista..."

PARTE 8: TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: El chatbot no inicia
──────────────────────────────
$ python app.py
Error: No module named 'flask'

SOLUCIÓN:
$ pip install -r requirements.txt

─────────────────────────────────────────────────────────────────────────────

PROBLEMA: El servidor inicia pero no carga vacantes
────────────────────────────────────────────────────
Ver logs: "Advertencia: No se pudo cargar vacantes.json"

CAUSAS:
- vacantes.json no existe
- JSON tiene sintaxis inválida
- Archivo en carpeta incorrecta

SOLUCIÓN:
1. Verifica que vacantes.json existe en la raíz
2. Valida JSON en jsonlint.com
3. Copia el contenido correcto desde .env.example

─────────────────────────────────────────────────────────────────────────────

PROBLEMA: El correo no se envía
────────────────────────────────
LOGS muestran: "Error de autenticación"

CAUSAS:
- MAIL_USER incorrecto
- MAIL_PASS incorrecto
- Archivo .env no existe o mal configurado

SOLUCIÓN:
1. Verifica .env existe en raíz
2. Valida MAIL_USER sea tu email completo
3. Usa contraseña de aplicación (no normal)
4. Reinicia servidor: Ctrl+C + python app.py

─────────────────────────────────────────────────────────────────────────────

PROBLEMA: Nueva vacante no aparece en el chatbot
──────────────────────────────────────────────
SOLUCIÓN:
1. Abre vacantes.json, verifica tu vacante
2. Valida JSON (jsonlint.com)
3. Reinicia servidor: Ctrl+C + python app.py
4. Prueba nuevamente
