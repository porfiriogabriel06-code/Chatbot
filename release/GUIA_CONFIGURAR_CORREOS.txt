═══════════════════════════════════════════════════════════════════════════════
    GUÍA COMPLETA: CONFIGURAR ENVÍO DE CORREOS DEL CHATBOT
═══════════════════════════════════════════════════════════════════════════════

Bienvenido. Esta guía te enseña a configurar el sistema de envío de correos
para que los CVs de los candidatos lleguen automáticamente a tu bandeja.

═══════════════════════════════════════════════════════════════════════════════
PARTE 1: ¿QUÉ ES LO QUE VAMOS A CONFIGURAR?
═══════════════════════════════════════════════════════════════════════════════

Cuando un candidato sube su CV en el chatbot, el sistema debe enviar
automáticamente un correo a Recursos Humanos con:

✓ Nombre del candidato
✓ Área seleccionada
✓ Tipo de puesto
✓ Respuestas de la entrevista
✓ CV como archivo adjunto (PDF)
✓ Fecha y hora de la postulación

Esto requiere:
1. Una cuenta de correo válida (Gmail, Outlook, etc.)
2. Contraseña de aplicación especial
3. Configurar un archivo llamado .env en el proyecto

═══════════════════════════════════════════════════════════════════════════════
PARTE 2: STEP-BY-STEP - CONFIGURACIÓN INICIAL
═══════════════════════════════════════════════════════════════════════════════

RESUMEN DE PASOS:
1. Crear o usar una cuenta de correo (Gmail recomendado)
2. Generar contraseña de aplicación
3. Crear archivo .env en la raíz del proyecto
4. Agregar variables de configuración
5. Probar que funcione

═══════════════════════════════════════════════════════════════════════════════
PARTE 3: OPCIÓN 1 - CONFIGURAR CON GMAIL (RECOMENDADO)
═══════════════════════════════════════════════════════════════════════════════

¿Por qué Gmail?
- Es GRATIS
- Fácil de configurar
- Muy confiable
- Buen soporte

PASO 1: Abre tu cuenta de Gmail (o crea una)
──────────────────────────────────────────
1. Ve a https://mail.google.com/
2. Inicia sesión (si no tienes cuenta, créala)
3. Utiliza un correo como:
   - reclutamiento@k83fyc.com
   - hr-candidatos@gmail.com
   - postulaciones-k83@gmail.com

⚠️ IMPORTANTE: Asegúrate de acceder a tu correo una vez desde el navegador
   para confirmar que está activo.

PASO 2: Habilita Acceso a Aplicaciones Menos Seguras
─────────────────────────────────────────────────────
1. Ve a tu cuenta Google: https://myaccount.google.com/
2. Haz clic en "Seguridad" en el menú izquierdo
3. Busca "Acceso a aplicaciones menos seguras"
4. Activa esa opción
5. Confirma tu identidad si te lo pide

⚠️ Si no ves esa opción, vas al PASO 3 en su lugar (Contraseña de Aplicación)

PASO 3: Generar Contraseña de Aplicación (MÁS SEGURO)
──────────────────────────────────────────────────────
Este es el método RECOMENDADO y SEGURO para 2024+.

1. Ve a https://myaccount.google.com/apppasswords
   (Requiere que hayas habilitado autenticación de dos factores)

2. Si NO tienes 2FA habilitado:
   a. Ve a https://myaccount.google.com/security
   b. Busca "Verificación en dos pasos"
   c. Sigue los pasos (tendrás que usar tu teléfono)
   d. Una vez completado, vuelve a apppasswords

3. En la página de App Passwords:
   a. Selecciona: Aplicación = "Correo"
   b. Selecciona: Dispositivo = "Windows, Mac o Linux"
   c. Haz clic en "Generar"

4. Google te mostrará una contraseña de 16 caracteres:
   Ejemplo: abcd efgh ijkl mnop
   
   ⭐ COPIA ESTA CONTRASEÑA EN UN LUGAR SEGURO (no es tu contraseña normal)

═════════════════════════════════════════════════════════════════════════════

PASO 4: Crear el archivo .env
──────────────────────────────
1. Abre el Explorador de archivos
2. Navega a tu carpeta del proyecto:
   C:\Users\[TuNombre]\OneDrive\Escritorio\chatbot-0.1\

3. Si ya existe un archivo ".env", abre ese
   Si NO existe, sigue estos pasos:
   a. Haz clic derecho en la carpeta vacía
   b. "Nuevo" → "Documento de texto"
   c. Copia lo siguiente:

═════════════════════════════════════════════════════════════════════════════

CONTENIDO DEL ARCHIVO .env (para Gmail):

───────────────────────────────────────────────────────────────────────────
# Configuración Flask
FLASK_ENV=production
FLASK_DEBUG=False
SECRET_KEY=tu-clave-secreta-muy-fuerte-aqui-cambia-esto

# Configuración de Correo - GMAIL
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USER=tu-email@gmail.com
MAIL_PASS=contraseña-de-aplicación-aquí
MAIL_FROM=tu-email@gmail.com

# Email del destinatario (donde recibirá los CVs)
RH_EMAIL=rh@k83fyc.com

# Otras configuraciones
UPLOAD_FOLDER=uploads
───────────────────────────────────────────────────────────────────────────

EXPLICACIÓN:
- MAIL_HOST        = Servidor SMTP de Gmail
- MAIL_PORT        = Puerto SMTP
- MAIL_USER        = Tu email de Gmail completo
- MAIL_PASS        = Contraseña de aplicación (la de 16 caracteres)
- MAIL_FROM        = Correo que aparecerá como remitente
- RH_EMAIL         = Correo donde recibirá los CVs (puede ser diferente)

EJEMPLO COMPLETO:

───────────────────────────────────────────────────────────────────────────
# Configuración Flask
FLASK_ENV=production
FLASK_DEBUG=False
SECRET_KEY=mi-clave-super-secreta-2026

# Configuración de Correo - GMAIL
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USER=reclutamiento@gmail.com
MAIL_PASS=abcd efgh ijkl mnop
MAIL_FROM=reclutamiento@gmail.com

# Email del destinatario (donde recibirá los CVs)
RH_EMAIL=maria.torres@k83fyc.com

# Otras configuraciones
UPLOAD_FOLDER=uploads
───────────────────────────────────────────────────────────────────────────

PASO 5: Guardar el archivo .env
────────────────────────────────
1. Escribe lo anterior en el archivo de texto
2. Presiona Ctrl+S
3. Cuando pida guardar como, elige:
   - Nombre: .env (exactamente así, con el punto)
   - Tipo: Todos los archivos (*.*)
   - Ubicación: Raíz del proyecto (chatbot-0.1)
4. Guarda

VERIFICACIÓN: Si ves un archivo con icono de configuración, ¡es correcto!

Si prefieres usar Outlook/Hotmail:

═══════════════════════════════════════════════════════════════════════════════
PARTE 6: PROBAR QUE FUNCIONA
═══════════════════════════════════════════════════════════════════════════════

Una vez hayas configurado el .env:

PASO 1: Inicia el servidor
──────────────────────────
1. Abre PowerShell o Terminal
2. Ve a la carpeta del proyecto: cd C:\Users\...\chatbot-0.1\
3. Ejecuta: python app.py
4. Deberías ver: "Running on http://localhost:5000"

PASO 2: Abre el chatbot en tu navegador
────────────────────────────────────────
1. Dirígete a: http://localhost:5000
2. Interactúa con el chatbot
3. Selecciona una vacante
4. Carga un CV (cualquier PDF)
5. Completa el proceso

PASO 3: Verifica que el correo llegó
────────────────────────────────────
1. Abre tu correo RH_EMAIL
2. Busca un nuevo correo de "Nuevas postulaciones"
3. Debería contener:
   ✓ Nombre del candidato
   ✓ Datos de la postulación
   ✓ CV adjunto

✅ ¡Si todo funcionó, tu configuración está correcta!

═══════════════════════════════════════════════════════════════════════════════
PARTE 7: SOLUCIONAR PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: "Error de autenticación"
──────────────────────────────────
Causas:
- MAIL_USER es incorrecto (escribe tu email completo)
- MAIL_PASS es incorrecta (usa la contraseña de aplicación, no la normal)
- El archivo .env no está guardado correctamente

SOLUCIÓN:
1. Verifica que MAIL_USER tenga el email COMPLETO (ej: usuario@gmail.com)
2. Copia de nuevo la contraseña de aplicación (si usas Gmail)
3. Guarda el .env y reinicia el servidor

───────────────────────────────────────────────────────────────────────────

PROBLEMA: "Conexión rechazada" o "No se puede conectar"
──────────────────────────────────────────────────────
Causas:
- MAIL_HOST es incorrecto
- MAIL_PORT es incorrecto
- El servidor está caído
- Tu firewall bloqu la conexión

SOLUCIÓN:
1. Verifica MAIL_HOST y MAIL_PORT (usa los de abajo)
   Gmail: smtp.gmail.com:587
   Outlook: smtp-mail.outlook.com:587
2. Si usas servidor personalizado, contacta a IT
3. Verifica tu conexión de internet

───────────────────────────────────────────────────────────────────────────

PROBLEMA: El correo no se envía pero no hay error
──────────────────────────────────────────────────
Causas:
- El archivo .env no se está cargando
- Hay un error silencioso en el código
- El servidor no se reinició después de cambiar .env

SOLUCIÓN:
1. Asegúrate de guardar .env
2. Presiona Ctrl+C en la terminal para detener el servidor
3. Ejecuta nuevamente: python app.py
4. Prueba de nuevo

───────────────────────────────────────────────────────────────────────────

PROBLEMA: "Error: MAIL_HOST no configurado"
────────────────────────────────────────────
Causa: El archivo .env no existe o no tiene MAIL_HOST

SOLUCIÓN:
1. Crea el archivo .env en la raíz del proyecto
2. Agrega todas las variables de configuración
3. Guarda con Ctrl+S
4. Reinicia el servidor

═══════════════════════════════════════════════════════════════════════════════
PARTE 9: CAMBIAR CORREO DESTINO (RH_EMAIL)
═══════════════════════════════════════════════════════════════════════════════

Si necesitas cambiar a quién llegan los CVs:

1. Abre el archivo .env
2. Busca la línea: RH_EMAIL=...
3. Cambia el correo:
   Antes: RH_EMAIL=rh@k83fyc.com
   Después: RH_EMAIL=maria@k83fyc.com
4. Guarda (Ctrl+S)
5. Reinicia el servidor

⚠️ Nota: El RH_EMAIL es diferente de MAIL_USER
   - MAIL_USER = Correo que ENVÍA los correos
   - RH_EMAIL = Correo que RECIBE los CVs

Ejemplo:
- Mail viene de: reclutamiento@gmail.com (MAIL_USER)
- Se envía a: maria.torres@k83fyc.com (RH_EMAIL)

PARTE 10: SEGURIDAD Y BUENAS PRÁCTICAS
═══════════════════════════════════════════════════════════════════════════════

IMPORTANTE - NUNCA HAGAS ESTO:
❌ NO compartas tu archivo .env con otros
❌ NO publiques tu .env en GitHub o redes sociales
❌ NO uses tu contraseña normal de Gmail (usa contraseña de aplicación)
❌ NO escribas las credenciales en el código directo

BUENAS PRÁCTICAS:
✅ Usa contraseña de aplicación (no normal)
✅ Cambia SECRET_KEY en producción
✅ Mantén .env en privado (ya está en .gitignore)
✅ Haz backup del .env en lugar seguro
✅ Usa un servidor de correo dedicado si es posible
